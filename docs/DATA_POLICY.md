# Data policy

This repository indexes public-record research data and preserves provenance.

Historical emails/phones are observations from source material, not assertions that an address or number remains active today. The pipeline intentionally does not perform SMTP probing, password recovery checks, account-enumeration checks, or other intrusive validation.

For publication, prefer public/professional contact fields and retain source/observation dates. Sensitive personal data should be minimized when it is not necessary to the research question.
